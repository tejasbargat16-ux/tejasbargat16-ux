# Tejas 2.0 Portfolio (React + Vite)

A cinematic, mobile-first personal portfolio for Tejas Bargat. Lives inside the profile repo and is deployed
to GitHub Pages at `/portfolio/` next to the TEJASFLIX site.

Standalone source: https://github.com/tejasbargat16-ux/Tejas-2.0-Portfolio

## Included
- React 19 + Vite, Netflix-inspired cinematic design, responsive/mobile-first
- Animated preloader, hero reveal, scroll animations, reduced-motion fallback
- 6 featured projects, 36-skill filterable taxonomy, Python Day 01 → 13 timeline, 2026 → 2028 roadmap
- NEXUS AI chat (local knowledge engine + optional Gemini/Groq/OpenAI backend) — see `README_NEXUS_AI.md`

## Run locally
```bash
npm install
npm run dev
npm run build    # outputs to dist/
npm run server   # optional NEXUS AI backend on :3001 (needs .env)
```

The site intentionally avoids invented employment, awards, clients, or mastery claims.
