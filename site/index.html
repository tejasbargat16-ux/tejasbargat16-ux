Tejas Bargat — Behind the Scenes

Tejas is an Electronics & Communication Engineering undergraduate (2nd Year) at TGPCET, RTMNU, with a minor in Computer Science. His philosophy is simple: "Build. Learn. Break. Fix. Repeat."

The Android-First Story: Without access to a personal laptop, Tejas turns constraint into superpower. Using Termux on Android, he configures complete Git, Node.js, and Python runtime environments to write code, manage SQLite databases, test APIs, and push daily GitHub commits directly from mobile hardware.
